Restaurant Finder
Restaurant Finder is a React Native mobile application that helps users discover restaurants based on their location, preferred cuisine, and search keywords. By integrating with the Yelp Fusion API, the application provides real-time restaurant information, allowing users to browse available dining options and access detailed restaurant data directly from their mobile device.

The application enables users to search for restaurants by city, cuisine, or restaurant name, view a list of matching results, and explore detailed information about each restaurant, including ratings, photos, addresses, phone numbers, pricing, and business hours when available. The project is designed to provide a clean, responsive, and user-friendly experience while demonstrating modern mobile development practices.

Project Overview
Restaurant Finder is developed using React Native and Expo and focuses on integrating live API data rather than using a local database. The application showcases key concepts learned throughout the course, including API integration, asynchronous programming, navigation between screens, reusable components, responsive layouts, and state management using React Hooks.

Features

Browse restaurant listings retrieved from the Yelp Fusion API

Access detailed restaurant information
Responsive mobile interface using Flexbox

Loading indicators and error handling
Reusable React Native components
Screens
Home & Search Screen
Users can enter a restaurant name, cuisine type, or location to begin their search.

Restaurant Results Screen
Displays restaurant results using FlatList with restaurant images, ratings, categories, and addresses.

Restaurant Details Screen
Provides detailed information about a selected restaurant, including photos, ratings, address, phone number, price range, and business hours when available.
