Restaurant Finder
Restaurant Finder is a React Native mobile application that helps users discover restaurants based on their location, 
preferred cuisine, and search keywords. The application uses the Yelp Fusion API to retrieve real-time restaurant data, 
including restaurant names, ratings, images, addresses, contact information, and business details. Users can search for restaurants,
browse results through an organized list, and view detailed information about selected restaurants. 
The application is built using React Native and Expo,
with Axios for API communication, React Navigation for screen navigation,
FlatList for efficient data rendering, and reusable components to maintain a clean and scalable code structure.
The project demonstrates modern mobile application development practices, responsive UI design using Flexbox, and integration with live third-party APIs.
